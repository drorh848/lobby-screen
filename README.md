# מסך לובי – בן גוריון 62 א, קרית ביאליק

## קבצים
| קובץ | תפקיד |
|---|---|
| `index.html` | המסך בטלוויזיה (שעון, תאריך עברי, מזג אוויר, שבת, לוח מודעות, מבזקי ynet) |
| `admin.html` | דף ניהול מהטלפון – הוספה/עריכה/מחיקה של הודעות לדיירים והגדרות |

## 1. Firebase
1. ליצור פרויקט חדש ב־Firebase Console.
2. **Realtime Database** → Create database (אזור europe-west1).
3. **Authentication** → Sign-in method → להפעיל Email/Password → Users → להוסיף משתמש לחבר (ולך).
4. Project settings → Your apps → Web app → להעתיק את `firebaseConfig`.
5. להדביק את הערכים ב־`CONFIG.FIREBASE` **בשני הקבצים** (`index.html` ו־`admin.html`).
6. Realtime Database → Rules – להדביק:

```json
{
  "rules": {
    "lobby": {
      "$building": {
        ".read": true,
        "messages": { ".write": "auth != null" },
        "settings": { ".write": "auth != null" },
        "status":   { ".write": true }
      }
    }
  }
}
```

## 2. רישיון
- `license-lobby.html` – מחולל הקודים. **נשאר רק בטלפון שלך, לא עולה ל־Netlify ולא נכנס לריפו.**
- במסך ההפעלה בטלוויזיה יש QR: החבר סורק → נפתחת הודעת וואטסאפ עם מזהה המכשיר → שולח לך.
- אצלך: מדביקים את כל ההודעה במחולל → הקוד מופק → "שלח בוואטסאפ".
- `ADMIN_PHONE` ב־`index.html` – אפשר להכניס את המספר שלך (9725XXXXXXXX) כדי שההודעה תגיע ישר אליך.
- `MASTER_SECRET` כבר מוגדר זהה ב־`index.html` וב־`license-lobby.html`. אם משנים – לשנות בשניהם.
- המחולל עובד גם כשנפתח ממנהל הקבצים (חישוב SHA-256 מובנה בקובץ).

### LicenseManager
- ב־`index.html` להחליף את `MASTER_SECRET` בסוד שלך.
- `APP_NAME = 'LobbyScreen'` – להגדיר זהה ב־LicenseManager.
- מיפוי ה־hash לקוד: 12 הבתים הראשונים של ה־SHA-256, כל בית `% 32` לתוך `LIC_CHARSET`, בפורמט `XXXX-XXXX-XXXX`.
  אם ב־LicenseManager שלך המיפוי שונה – להתאים את הפונקציה `expectedKey()`.

## 3. העלאה ל־Netlify
פונקציות Netlify לא עולות בגרירה (Drag & Drop), לכן:
1. ליצור ריפו ב־GitHub עם שלושת הקבצים במבנה הזה.
2. ב־Netlify: Add new site → Import from Git → לבחור את הריפו → Deploy.
3. כתובות:
   - מסך: `https://<site>.netlify.app/`
   - ניהול: `https://<site>.netlify.app/admin.html`

אם הפונקציה לא זמינה, המסך עובר אוטומטית ל־rss2json כגיבוי.

## בדיקה בטלפון לפני הטלוויזיה
1. טלפון אחד (או טאב בכרום): לפתוח את כתובת המסך, לסובב לרוחב → מסך ההפעלה.
2. להעתיק את המזהה ← להדביק ב־`license-lobby.html` ← להקליד את הקוד → המסך עולה.
3. טלפון שני / טאב אחר: לפתוח `admin.html` → אמור להופיע 🟢 "המסך מחובר".
4. לפרסם הודעה רגילה, חשובה ודחופה → לראות שהיא קופצת מיד במסך.
5. בהגדרות: "רענן את המסך עכשיו" → המסך נטען מחדש.

> הרישיון קשור לדפדפן שבו הופעל. בטלוויזיה יהיה מזהה חדש, ויופק לו קוד נפרד.

## 4. הטלוויזיה (ניאון 32")
1. לחבר סטיק Android TV (למשל Xiaomi TV Stick) ל־HDMI.
2. להתקין **Fully Kiosk Browser** מה־Play Store.
3. בפעם הראשונה לפתוח את כתובת המסך → יופיע מזהה מכשיר → להפיק לו קוד ב־LicenseManager.
4. להגדיר ב־Fully Kiosk את כתובת ההתחלה:
   `https://<site>.netlify.app/?key=XXXX-XXXX-XXXX`
5. ב־Fully Kiosk: הפעלה אוטומטית עם עליית המכשיר, מסך תמיד דלוק, נעילת קיוסק.
6. בטלוויזיה: לכבות "כיבוי אוטומטי/חיסכון בחשמל" אם יש.

> אם מנקים את נתוני הדפדפן בסטיק – מזהה המכשיר משתנה ויש להפיק קוד חדש.

## 5. ניהול מהטלפון
- לפתוח את `admin.html` בטלפון → להתחבר עם המשתמש מ־Firebase.
- להוסיף למסך הבית: בכרום תפריט ⋮ ← "הוספה למסך הבית" (באייפון: שיתוף ← "הוסף למסך הבית").
- למעלה מופיע אם המסך בלובי מחובר (🟢 / 🔴).
